# ChatVora AGI - Launch Instructions

ChatVora AGI is a sophisticated neural intelligence platform built with React, Tailwind CSS, and Gemini AI.

## 🚀 How to Launch

### 1. In Google AI Studio
This application is **automatically launched** in the development environment. 
- You can view it in the **Preview** pane on the right side of the screen.
- For the best experience, click the **"Open in new tab"** icon at the top of the Preview pane.

### 2. Local Development
If you have downloaded the code to your local machine:
1. **Install Dependencies:**
   ```bash
   npm install
   ```
2. **Environment Variables:**
   Create a `.env` file and add your Gemini API Key:
   ```env
   VITE_GEMINI_API_KEY=your_actual_key_here
   ```
3. **Run Dev Server:**
   ```bash
   npm run dev
   ```
   The app will typically be available at `http://localhost:3000`.

### 3. Production Deployment
To deploy this application permanently:
1. Go to the **Settings** menu in Google AI Studio.
2. Select **Deploy to Cloud Run**.
3. Follow the prompts to receive a permanent public URL for your platform.

## 🧠 Key Features
- **Neural Agents:** Build specialized AI personalities for any subject.
- **AgentBrain™:** Manage global knowledge fragments and heuristics.
- **Workspaces:** Organize your research and discussions into separate neural zones.
